    PaperManager¶

    How it works¶

    1

    Add a paper¶

    Drag in a PDF or paste an arXiv, DOI or PubMed link. The metadata is looked up for you; you check it and press save.

    2

    PaperManager reads it¶

    In the background it writes a summary, pulls out figures, tables and references, and suggests topics and tags.

    3

    You read, ask and connect¶

    Read the PDF with the summary, a guided tour and visual explanations beside it, then ask questions across everything you have read.

    New here? First steps walks through one paper from upload to concept map in about ten minutes.

    What you get¶

    One library for every paper¶

    Search the full text, filter by project, topic, tag, author or reading status, and see at a glance what is still unread.

    Library

    Everything about a paper in one view¶

    The left side switches between the PDF, the summary, figures, tables, references and related papers. The right side keeps your notes, highlights and a chat about the paper open beside it.

    Reading a paper

    A guided tour through a long paper¶

    An overview, what you can skip, and 6–12 stops that jump to the passages that matter, with the concepts each one relies on.

    Concepts, tour and concept map

    How a whole project fits together¶

    The key concepts of every paper in a project and how they relate, as a graph you can filter by author, year and kind of concept.

    Concept map

    Ask your whole library¶

    The knowledge chat answers from your papers and cites them. Narrow it with @project:, @topic: or @paper:, or let it search the web too.

    Knowledge chat

    Under the hood¶

    graph LR
    UI["React app"] --> API["FastAPI backend"]
    MCP["Claude via MCP"] --> API
    API --> DB[("Neo4j<br/>knowledge graph")]
    API --> Drive["Google Drive<br/>PDFs and figures"]
    API --> LLM["Claude / any<br/>OpenAI-compatible model"]
    API --> Ext["Semantic Scholar<br/>CrossRef · arXiv"]

    Every paper, author, topic, project, note and concept is a node in one Neo4j graph, so the same data powers the library, the chat, the concept map and the Cypher editor. PDFs stay in your own Google Drive. More in Architecture.

    PaperManager is open source. The project page at niklas-abraham.de has the story behind it; issues and pull requests are welcome on GitHub.
